# Dao · 道 App 产品需求文档（PRD + UI设计）

## 📌 一、产品概述

### 1.1 产品定位

Dao · 道 是一款以东方哲学为核心的文化类应用，通过极简设计与 AI 解读，帮助用户理解道教思想，并在现代生活中应用。

### 1.2 核心价值

* 用现代语言解释传统思想
* 提供可阅读、可思考的内容体验
* 打造“文化 + AI”的轻应用

---

## 🎯 二、目标用户

* 对东方哲学感兴趣的人
* 喜欢极简内容阅读的人
* 有自我成长/冥想需求的用户
* 海外用户（对中国文化感兴趣）

---

## 🧭 三、产品结构

```
首页 | 思想 | 人物 | 派系 | 搜索
```

## 🏠 四、首页模块

### 4.1 功能

* 今日一句（道德经）
* AI解读
* 推荐内容（人物 / 思想）

### 4.2 UI结构

```
标题：今日一言

[语录卡片]
道可道，非常道...

[按钮] AI解读

[AI解释卡片]

[横滑推荐]
人物 / 思想
```

### 4.3 交互

* 点击 AI解读 → 展示解释（淡入动画）
* 推荐模块支持横向滑动
